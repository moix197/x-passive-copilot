# `.ai/` — Project Knowledge Base

Source of truth for project knowledge (see CLAUDE.md). Shaped like a local RAG:
**one file = one retrievable chunk**, indexes **generated** from entry frontmatter.
This README owns the *format*; the `sync-knowledge` skill owns the *procedure*
for writing and syncing entries — don't edit `.ai/` ad hoc.

## The rule: decision-oriented, not a wiki

> `.ai/` captures **decisions, constraints, invariants, and the map of where things
> live** — the non-obvious *why*. If a doc could be regenerated by reading the
> code, it doesn't belong here.

## Layout

```
.ai/
  README.md              # this spec (hand-written)
  index.md               # ROOT index, fully generated: domain | scope | active entry count
  <domain>/index.md      # hand-written `scope:` + optional short intro; entry table generated
  <domain>/<slug>.md     # atomic entry
  _tools/build-index.mjs # zero-dependency generator + linter
```

- Folders are **domains** — what you're working on (`architecture`, `auth`, `data`,
  `ui`, `tooling`...), never doc types. Type lives in frontmatter.
- One level deep, kebab-case names. Folders starting with `_` are not domains.
- A domain `index.md` has frontmatter `scope: <one line>` and a generated region
  between `<!-- entries:start -->` and `<!-- entries:end -->` (exactly one of
  each, in that order). Never hand-edit inside the markers, nor the root `index.md`.
- Create a domain when an entry fits no existing scope — not speculatively.

## Entry frontmatter

Strict and flat. Scalars unquoted on one line, arrays inline `[a, b]`, no other
YAML features — the parser is deliberately trivial. There is no comment syntax:
a trailing `# note` becomes part of the value. Every field below is required
except `superseded_by`; unknown or duplicate fields are lint errors.

```
---
id: <domain>/<slug>
type: decision | pattern | constraint | gotcha | howto | map
summary: <one line, <=160 chars>
tags: [kebab, case]
paths: [packages/auth/**]
related: [<domain>/<slug>]
status: active | superseded
superseded_by: <domain>/<slug>
updated: YYYY-MM-DD
---
```

| Field | Rule |
| --- | --- |
| `id` | Equals the file path relative to `.ai/`, minus `.md`. Slug (file name) is kebab-case. |
| `summary` | What gets retrieved/embedded. Write it as the answer, not a title. |
| `paths` | Repo-relative globs of the code the entry concerns; `[]` allowed. The static prefix must exist (dead-path check). |
| `related` | Entry ids; `[]` allowed. Must resolve. |
| `superseded_by` | Required when `status: superseded`, forbidden when `active`. Must resolve. |
| `updated` | A real calendar date, `YYYY-MM-DD`. |

## Entry body

- **One entry answers one question.** Hard cap: **80 lines** (excluding
  frontmatter). Over the cap => split into multiple entries.
- `decision` entries use: `**Decision:**` / `**Why:**` / `**Rejected:**` /
  `**Constraints it creates:**`.
- `pattern` entries only on the **2nd real use**, never speculatively.
- A change is an **edit in place**, a **supersede** (new entry + old one marked
  `superseded`) only when the old entry's history still explains live code, or a
  **delete** when the subject is gone. Never append a changelog.

## Read protocol

1. `.ai/index.md` — pick the domain(s) matching the task.
2. `<domain>/index.md` — scan the Summary / Tags / Paths columns.
3. Open **only** the entries that match. Never bulk-read a domain folder.
   Superseded entries are listed separately; read them only for history.

## Generator + linter

```
node .ai/_tools/build-index.mjs          # lint, then regenerate root index + domain regions
node .ai/_tools/build-index.mjs --check  # write nothing; exit 1 on lint error or stale index
```

Lint errors print as `file: message` and block all writes. It enforces every rule
above (schema, enums, caps, resolvable ids, dead `paths`, kebab-case names/tags,
domain `scope` + markers). Output is deterministic (sorted by id, LF) and
idempotent. `--check` must pass before work is considered done.

## Future MCP/RAG migration

Each entry is already one chunk: `summary` + body become the embedded text;
frontmatter (`type`, `tags`, `paths`, `status`, domain from `id`) becomes metadata
filters; `related` / `superseded_by` become graph edges; the read protocol becomes
a filtered similarity query. No content rewrite — only a loader reusing this parser.
